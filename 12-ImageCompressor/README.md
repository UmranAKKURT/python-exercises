# Image Compressor Pro

A professional desktop image compressor built with Python. Features a modern sidebar UI, format conversion, EXIF metadata management, and multi-threaded batch compression.

## Features

- Modern Dark/Light Theme with Sidebar UI
- Drag & Drop Support
- Smart Compression Mode
- Format Conversion (Original, JPG, PNG, WEBP)
- EXIF Metadata Preservation/Removal
- Multi-threaded Batch Compression
- Interactive Image Preview & Zoom
- Compression History & Statistics

## Technologies

- Python
- Tkinter & ttkbootstrap
- Pillow
- tkinterdnd2 (for Drag & Drop)
